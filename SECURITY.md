# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues, discussions or pull requests.

Report it privately through GitHub at
https://github.com/MAcemek/ai-agent-checkup/security/advisories/new, or use the "Report a
vulnerability" button on the Security tab of the repository.

Please include the affected version, a description of the problem and its impact, and the steps
to reproduce it.

A workflow pattern that ai-agent-checkup misses is usually a normal bug or feature request. Report
it privately only if it is a problem in ai-agent-checkup itself, for example a crafted workflow
file that makes it run code or write files.

## How reports are handled

- We acknowledge your report within 7 days.
- We confirm the problem, keep you informed and agree on a disclosure date with you, normally
  within 90 days of your report.
- We release a fix and publish a GitHub security advisory that describes the vulnerability, the
  affected versions, its severity and how to update.
- We credit you in the advisory unless you prefer not to be named.

## Supported versions

ai-agent-checkup is a free, non-commercial open-source project. Only the latest release receives
security updates. There is no fixed support period or end date.
